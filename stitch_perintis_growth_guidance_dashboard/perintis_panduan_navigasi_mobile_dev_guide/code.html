Spesifikasi State & Navigasi

memory State Persistence (IndexedStack)

Tiap tab wajib mempertahankan scroll position dan input form saat berpindah tab. Gunakan AutomaticKeepAliveClientMixin (Flutter) atau detachInactiveScreens: false (React Navigation).

arrow_back Back Stack Behavior

Tekanan tombol Back fisik/gesture pada sub-halaman (/direction/*) harus memunculkan pop dari nested navigator tab aktif terlebih dahulu. Jika berada di root tab non-beranda, klik Back akan mengembalikan ke Tab Beranda sebelum keluar aplikasi.
